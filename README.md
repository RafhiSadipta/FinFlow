## 🚀 Ringkasan Tech Stack
- **Frontend**: React (TypeScript) + Vite + Tailwind CSS (Obsidian Wealth Glassmorphic Theme)
- **Mobile Container**: Capacitor 6 (Android APK & iOS)
- **Backend API**: Golang (Go Fiber / Gin) dengan Clean Architecture
- **Database & Storage**: Supabase Cloud (PostgreSQL 15+ & Storage)
- **CI/CD & Deployment**: GitHub Actions (Otomatis Build APK) + Vercel (Web Live Demo)
